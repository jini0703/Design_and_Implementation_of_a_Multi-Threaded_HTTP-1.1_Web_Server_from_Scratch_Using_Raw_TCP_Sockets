State Machine Invariants
NORMAL: Queue < 70%, p95 wait < 25 ms, p95 latency < 50 ms. High worker load alone with short queue remains NORMAL.
CAUTION: Queue ≥ 70%, p95 wait ≥ 25 ms, or workers 100% + queue ≥ 50%. Bounded keep-alive (max 16 requests, 1s idle timeout).
OVERLOAD: Queue ≥ 90%, p95 wait ≥ 100 ms, p95 latency ≥ 150 ms, or sustained pressure. Immediate HTTP 503 shedding with Retry-After: 5.
*Recovery requires consecutive healthy windows below caution thresholds (hysteresis dampening).
